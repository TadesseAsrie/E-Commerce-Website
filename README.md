# ShopHub - Modern E-Commerce Frontend

A fully responsive, modern e-commerce frontend built with React.js, Vite, Tailwind CSS, and React Router. Features include product browsing, cart management, wishlist, checkout simulation, dark mode, and persistent local storage.

![ShopHub Preview](https://via.placeholder.com/800x400?text=ShopHub+E-Commerce+Demo)

## ✨ Features

- **Modern UI/UX** – Clean design inspired by Amazon/Shopify
- **Product Catalog** – Grid layout with search, filters (category, price), sorting, and pagination
- **Product Details** – Image gallery, quantity selector, specs, and related products
- **Shopping Cart** – Add/remove items, update quantities, calculate totals
- **Wishlist** – Save products, move to cart
- **Checkout** – Shipping form, payment method selection (frontend simulation)
- **Persistent Data** – Cart & wishlist saved in `localStorage`
- **Dark Mode** – Toggle light/dark theme (user preference saved)
- **Responsive** – Mobile-first design, works on all devices
- **Animations** – Smooth page transitions and hover effects (Framer Motion)
- **Toast Notifications** – Feedback for cart/wishlist actions
- **Loading Skeletons** – Improved perceived performance
- **Scroll to Top** – Button appears after scrolling

## 🛠️ Technologies Used

- [React 18](https://reactjs.org/) – UI library
- [Vite](https://vitejs.dev/) – Build tool & dev server
- [React Router DOM](https://reactrouter.com/) – Client-side routing
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first styling
- [React Icons](https://react-icons.github.io/react-icons/) – Icon library
- [Framer Motion](https://www.framer.com/motion/) – Animations
- [Swiper](https://swiperjs.com/) – Hero slider & testimonial carousel
- [React Toastify](https://fkhadra.github.io/react-toastify/) – Notifications
